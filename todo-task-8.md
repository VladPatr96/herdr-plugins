# Задача #8: что сделать вам и что менялось вне репозитория

Задача: https://github.com/VladPatr96/herdr-plugins/issues/8

Плагин `file-board` подключён к вашему herdr, хоткей добавлен, nvim поставлен.
Осталось проверить руками.

## 1. Нажмите Alt+Shift+F

Сбоку от агента, на котором нажали, откроется панель с деревом его рабочей
папки:

```
 D:\projects\my_projects\herdr_plugins
▸ agent-hotkeys
▸ docs
▾ file-board
  ▸ bin
    package.json
  README.md

 j/k move · Enter open · e nvim · . hidden · r refresh · q close
```

Если по хоткею ничего не происходит — herdr читает `config.toml` при запуске, а
новую привязку подхватывает только после перезагрузки конфига:

```sh
herdr server reload-config
```

(то же самое — пункт `reload config` в общем меню herdr). Уже сделано, но если
правите привязку сами — нужно повторить. Проверить плагин без хоткея можно так:

```sh
herdr plugin action invoke vladpatr96.file-board.open
```

## 3. Что изменилось вне репозитория

1. **Поставлен Neovim 0.12.5** — `winget install --id Neovim.Neovim`, лёг в
   `C:\Program Files\Neovim`. Откат: `winget uninstall --id Neovim.Neovim`.
2. **Хоткей в `%APPDATA%\herdr\config.toml`** — в конец дописан блок
   `[[keys.command]]` с `alt+shift+f` → `vladpatr96.file-board.open`.
   Бэкап до правки: `config.toml.bak-file-board` рядом. Откат:
   `cp config.toml.bak-file-board config.toml`.
3. **Плагин подключён ссылкой** — `herdr plugin link D:\projects\my_projects\herdr_plugins\file-board`.
   Откат: `herdr plugin unlink vladpatr96.file-board`.
4. **Состояние плагина** — `side-pane.json` (какая панель открыта в каком
   воркспейсе) в каталоге состояния плагина herdr. Удаляется вместе с плагином.

Ничего из этого не трогает стоковый herdr и другие плагины.
