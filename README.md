# herdr-plugins

Plugins for [Herdr](https://herdr.dev), the terminal workspace manager for AI coding agents.

| Plugin | What it does |
|---|---|
| [agent-hotkeys](agent-hotkeys/) | Every agent gets its own hotkey (`Alt+1`, `Alt+2`, … `Alt+Q` …) when it starts, shown next to it in the sidebar. |
| [agent-tasks](agent-tasks/) | Give a task to a whole agent session, not a subagent: it opens in its own tab with its task, status and plan in the sidebar, and you can step into it and keep talking. |
| [quota-board](quota-board/) | One window with every AI quota you spend: Claude Code, Codex, agy, Grok, OpenCode Go and the DeepSeek API balance. |

Install a plugin with `herdr plugin install VladPatr96/herdr-plugins/<plugin>`.
